# Ruang Panggul Ibu

> **Edukasi Digital Pelatihan Otot Dasar Panggul (Senam Kegel) Berbasis Website Interaktif untuk Mencegah Inkontinensia Urine pada Ibu Hamil**

Website media promosi kesehatan (promkes) mandiri berbasis bukti ilmiah yang dirancang khusus untuk mendampingi ibu hamil (terutama trimester 2 dan 3) dalam memahami pentingnya kesehatan otot dasar panggul, mencegah serta mengatasi kebocoran urine (*stress urinary incontinence*), dan mempersiapkan persalinan yang nyaman serta minim trauma.

---

## Fitur Utama

1. **Struktur Pembelajaran 8 Bab**:
   - **Bab 01 — Beranda & Pengantar**: Sekilas program, latar belakang, dan navigasi cepat.
   - **Bab 02 — Apa itu Inkontinensia Urine?**: Definisi, perbedaan dengan air ketuban/keputihan, dan faktor penyebab kehamilan.
   - **Bab 03 — Kenali Otot Dasar Panggul**: Sketsa interaktif anatomi dasar panggul (bebas gambar eksplisit/vulgar, fokus pemahaman letak dan fungsi).
   - **Bab 04 — Apa itu Senam Kegel?**: Manfaat klinis bagi ibu hamil dan pascamelahirkan.
   - **Bab 05 — Ruang Latihan & Timer Meditatif**: Timer latihan dengan animasi denyut napas (*breathing pebble*), preset ritme (Pemula, Standar, Lanjutan, Custom), nada suara panduan lembut (*gentle chimes* via Web Audio API), serta panduan posisi bertahap.
   - **Bab 06 — Anjuran & Pantangan**: Tips aman, kesalahan umum, dan tanda bahaya kapan harus segera ke tenaga medis.
   - **Bab 07 — Evaluasi Pemahaman**: Kuis interaktif 5 soal dengan penjelasan langsung dan sistem skor otomatis.
   - **Bab 08 — Kepustakaan**: Referensi ilmiah kedokteran & kebidanan serta *disclaimer* medis.

2. **Desain Editorial & Responsif**:
   - Tipografi elegan Newsreader serif + Plus Jakarta Sans.
   - Skema warna hangat ramah ibu (*warm cream, sage green, dusty rose*).
   - Ramah layar sentuh (*mobile-friendly*) dan navigasi tab instan tanpa reload halaman.

3. **Murni Tanpa Dependensi Berat (Pure Vanilla)**:
   - Berjalan langsung di browser apa pun tanpa memerlukan Node.js server, bundler, atau library pihak ketiga.

---

## Teknologi yang Digunakan
- **HTML5**: Struktur semantik aksesibel.
- **CSS3**: Tata letak fleksibel (CSS Grid & Flexbox), CSS Custom Properties, desain responsif.
- **JavaScript (ES6+)**: Logika tab navigasi, timer state machine, Web Audio API chime synthesis, dan sistem scoring kuis.

---

## Cara Menjalankan
Buka file `index.html` langsung di browser favorit Anda (Google Chrome, Mozilla Firefox, Microsoft Edge, atau Safari), atau gunakan ekstensi seperti Live Server di VS Code.
